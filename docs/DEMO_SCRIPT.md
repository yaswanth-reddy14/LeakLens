## Recording discipline

Keep the comparison label and simulation banner visible. Read the values actually on screen rather than promising a fixed amount. If SAM startup or the smoke test is slow, show its real completed output from the same rehearsal and explain it as a local test. Never imply the terminal is a deployed AWS service. Keep credentials, browser account tabs and account identifiers off screen. Do not add a fake hosted URL. The full rules require AWS use to appear in the video, not only in the writeup.

If a workflow action fails, stop recording, use [DEMO_CHECKLIST.md](DEMO_CHECKLIST.md), and record a fresh take. The screenshots are supporting evidence, not a fabricated demo recording.
